How it works

Describe an image, choose how the model should interpret it, then compare the artwork, timing, and cost.

  1. 01

    Choose a path

    Use Jev or another model to populate the built-in art controls. Choose Custom code when those controls are not expressive enough.

  2. 02

    Write a prompt

    Enter your own idea or start with a prompt example. Select Compose to generate the artwork.

  3. 03

    Inspect the result

    Decision trace shows the applied visual choices. Session receipt records AI Gateway calls, latency, tokens, and reported cost.
