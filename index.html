How it works

This playground lets you create and download abstract creations, with a focus on programmatic generation via canvas-sketch to compare fidelity, speed, and cost across models. Built to showcase Jev’s speed: turning natural language into abstract art through parallel, structured decisions.

Jev (fastest, live)

Selective decision routingUpdates the fixed renderer as you type. Jev identifies the important parts, such as palette, composition, marks, space, and motion, and routes the relevant choices across 80+ typed characteristics. Select Compose to also check whether a prompt should be handed to custom code.

Other models

Complete spec in one callFills every field in the renderer spec at once, without Jev’s selective routing. This provides a direct baseline for comparing the result, cost, and speed.

Custom code + sandbox (most expressive)

Beyond the fixed specWhen prefilling the renderer spec is not expressive enough, Claude Sonnet 4.6 writes custom JavaScript and runs it in Vercel Sandbox.

Image generation

Prompt-to-imageAn image model renders the prompt directly. Unlike the other paths, this result is not produced by the canvas-sketch renderer.
